# Overview
A lightweight, front‑end Kitchen Display System built with HTML + Bootstrap 5 + jQuery + PapaParse,
that pulls CSV order exports and renders them as responsive order cards on an in‑house server.
## Technical side
Includes an Admin panel for uploading/replacing CSVs, toggling order status (New → In‑Progress → Complete), filtering by station, due windows (ST/DT), and 3‑day look‑ahead.
## Overall goal
Status: KDS in active development. The primary goal is to save Grade‑A Catering measurable time and cost on average by improving efficiency with this software.
